# Codex Diary: Free Claude Prompts

All the prompts from the Codex Diary videos in one place.
Replace anything in [BRACKETS] with your own details, then paste into Claude.

Channel: https://youtube.com/@codexdiary

## 1. YouTube Channel Helper

```
I run a YouTube channel about [TOPIC]. My audience is [WHO WATCHES].
Give me:
1. 10 video ideas that fit this topic, each with a title under 60 characters
2. For the 3 best ideas, a hook for the first 3 seconds
3. A thumbnail idea for each, using 4 words or fewer of on-screen text
Keep titles specific and result-focused. No clickbait I can't deliver on.
```

## 2. Make a 3D Video With Code

```
Build a single HTML file that shows a short 3D animated scene using Three.js
from a CDN. The scene: [DESCRIBE SCENE, e.g. a small robot walking across a
desk].
Requirements:
- Smooth camera movement and good lighting
- Runs by opening the file in a browser, no setup
- Loops every 10 seconds
- Clean, readable code with comments
Return only the complete file.
```

## 3. Recreate a Website From a Screenshot

```
I'm attaching a screenshot of a website.
Recreate it as a single HTML file with inline CSS.
- Match the layout, colors, spacing, and fonts as closely as you can
- Make it responsive for mobile
- Use placeholder text and images where needed
Return only the complete file, then list 3 things you couldn't match exactly.
```

## 4. Make AI Writing Sound Human

```
Rewrite the text below so it sounds like a real person wrote it.
Rules:
- Short sentences. Mix in a few very short ones.
- Cut filler words and phrases like "in today's world" or "it's important to note"
- Use plain words instead of fancy ones
- Keep the original meaning and facts
- No lists unless the original has one
Text: [PASTE TEXT HERE]
```

## 5. Five Everyday Time-Saving Prompts

**Summarize**
```
Summarize this in five bullet points, then list what I should do next.
[PASTE TEXT]
```

**Email**
```
Rewrite this email so it's shorter and sounds confident.
[PASTE EMAIL]
```

**Learn**
```
Explain [TOPIC] like I'm new to it, then ask me 5 questions to test me.
```

**Review**
```
Find the mistakes in this. Don't fix them yet, just list them with why.
[PASTE TEXT OR CODE]
```

**Plan**
```
Turn these messy notes into a clean step-by-step plan with deadlines.
[PASTE NOTES]
```

## 6. Learn Any Skill in 7 Days

```
I want to learn [SKILL] in 7 days. I can spend [TIME] per day. My level: [BEGINNER / SOME EXPERIENCE].
Build me a 7-day plan with a clear goal for each day.
Then teach day 1 now.
After that, at the start of each new day I'll say "next day". When I do:
1. Quiz me on yesterday in 5 questions
2. Teach the new day's topic
3. Give me one small task to complete
```

## 8. Summarize a Long Document

```
Read the attached document and give me:
1. A 5-sentence summary
2. The 5 most important points
3. Any numbers, dates, or deadlines mentioned
4. Anything that seems unclear or missing
Be accurate. If something isn't in the document, say so instead of guessing.
```

## 9. CLAUDE.md Starter for Claude Code

Save this as `CLAUDE.md` in the root of your project.

```
# Project
[ONE SENTENCE ABOUT WHAT THIS PROJECT DOES]

# Tech stack
- Language: [E.G. PYTHON 3.12]
- Framework: [E.G. FASTAPI]
- Database: [E.G. POSTGRES]

# Rules
- Follow the existing code style
- Write tests for new functions
- Don't add new dependencies without asking
- Explain what you changed after each task

# Commands
- Run: [COMMAND]
- Test: [COMMAND]

# Avoid
- [THINGS CLAUDE SHOULD NOT DO, E.G. EDITING THE /legacy FOLDER]
```

## 10. Make a Full Video With Code

```

Step 1: Write a voiceover script of about [WORD COUNT] words, split into scenes.
Step 2: For each scene, describe the visuals and on-screen text.
Step 3: Build the scenes as code that can render to video.
Do step 1 and 2 first and wait for my approval before writing code.
```
